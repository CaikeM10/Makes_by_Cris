# Referências do Painel Administrativo

Estas imagens são referências visuais criadas na v0.

Elas NÃO representam a lógica definitiva do sistema.

A fonte de verdade funcional é o catálogo atual existente no repositório.

## Objetivo do painel

O painel será um editor simples do catálogo da Makes by Cris Martins.

A proprietária deve conseguir:

- localizar rapidamente um produto;
- trocar foto;
- editar nome;
- editar descrição;
- alterar preço PIX;
- alterar preço crédito;
- alterar categoria;
- ativar/desativar produto;
- cadastrar novo produto;
- visualizar o resultado no catálogo público.

## Princípio de UX

Escolher o que quero alterar
→ alterar
→ salvar
→ ver no catálogo.

## Importante

As telas da v0 são apenas referência visual e de fluxo.

Alguns comportamentos demonstrativos estão incorretos.

Exemplo:

Destaques da semana NÃO deve abrir diretamente um produto.

Deve abrir todos os produtos pertencentes à seção e permitir escolher qual editar.

O mesmo vale para:

- Mais vendidos;
- Presentes & Kits;
- Novidades;
- Categorias.

O Codex deve sempre confrontar essas referências com o código real antes de propor implementação.
